# secJob

מחשבון אינטראקטיבי בעברית לבדיקת מס הכנסה לפי שכר ברוטו חודשי, מותאם לפתיחה באייפון דרך GitHub Pages.

## גרסה נוכחית

v0.0.2

## מה קיים בגרסה זו

- הזנת משכורת ברוטו חודשית בעבודה הראשית.
- חישוב מס הכנסה לפי מדרגות חודשיות לשנת 2026.
- הצגת מס שולי נוכחי ושיעור מס ממוצע.
- פירוט כמה כסף נופל בכל מדרגת מס וכמה מס יוצא מכל מדרגה.
- יעד נטו נוסף מעבודה שנייה.
- חישוב כמה ברוטו נוסף נדרש כדי להגיע ליעד הנטו.
- חישוב כמה שעות עבודה נדרשות לפי שכר שעתי ברוטו.
- ממשק RTL בעברית, מותאם מובייל ואייפון.

## מגבלות חישוב בגרסה זו

החישוב כולל מס הכנסה בלבד. הוא עדיין לא כולל:

- נקודות זיכוי.
- ביטוח לאומי.
- מס בריאות.
- הפרשות פנסיוניות.
- קרן השתלמות.
- תיאום מס בין עבודות.

## קבצים

- `index.html` - מבנה המסך.
- `styles.css` - עיצוב רספונסיבי לאייפון ודסקטופ.
- `app.js` - לוגיקת חישוב המס והעבודה השנייה.
